#### Access to EC2

1. Access AWS EC2, and open EC2 instance DevAxWindowsHost.
2. Click **Connect**.

![RemoteInstances](/images/1/6.png?width=90pc)

3. Select **RDP** tab, then click **Download remote desktop file** to download RDP file to remote access.
4. Click **Get password**.

![RemoteInstances](/images/1/7.png?width=90pc)

5. Click **Upload private key file** and select **KPforDevAxInstances** keypair to decrypt password for windows virtual.
6. Click **Decrypt password**.

![RemoteInstances](/images/1/8.png?width=90pc)

7. Copy passowrd and used to log into the Windows virtual machine.

![RemoteInstances](/images/1/9.png?width=90pc)

#### Config Eclipse IDE
8. Open the command line and configure the profile for the workshop.

{{%notice tip%}}
Please create access key and secret access key for **awsstudent** user generated by Cloud Formation Template in preparation section and use it to config awscli.
Also, go to the IAM console, select **IAM User** awsstudent, then select **Permissions**, **Add permissions**|**Attach existing policy directly** and select **AdministratorAccess**.
{{%/notice%}}

```bash
aws configure set profile.aws-lab-env.region <your-region>
aws configure set profile.aws-lab-env.aws_access_key_id <your_access_key_id>
aws configure set profile.aws-lab-env.aws_secret_access_key <your_secret_access_key>
```

![EclipseIDE](/images/1/10.png?width=90pc)

9. Open **Eclipse IDE**, in Eclipse IDE Launcher window, leave the default option and click **Launch**. Click **Finish** for the AWS Toolkit crawl window.

![EclipseIDE](/images/1/11.png?width=90pc)

10. Click **Restore**.

![EclipseIDE](/images/1/12.png?width=90pc)

11.  Click AWS symbol and select Click vào biểu tượng AWS and select the arrow, then select **Preferences**.

![EclipseIDE](/images/1/13.png?width=90pc)

12. Set **Default Profile** is **aws-lab-env**.
13. Select **Apply and Close**.

![EclipseIDE](/images/1/14.png?width=90pc)

#### Setting S3 buckets
You need to create 2 buckets. A bucket will contain the lambda function to be uploaded and a bucket used to store the image.

12. Create S3 bucket to store Lambda function code. You can use the AWS Console or use the command line:
```bash
aws s3 mb s3://idevelop-sourcecode-<yourinitials> --region <region> --profile aws-lab-env
```

with **<bucket-name>** is the unique name for your bucket. Replace **<region>** with the region that matches your practice.

13.  Create another bucket to store uploaded images. Similar to the above step, we name the S3 bucket **idevelop-imagemanager-<yourinitials>**. The command will be as follows:
```bash
aws s3 mb s3://idevelop-imagemanager-<yourinitials> --region <region> --profile aws-lab-env
```
